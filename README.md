# JobConnect-Job-Portal
A full-stack job portal built with React, Java Spring Boot, and MySQL, featuring job search, PDF resume uploads, recruiter application management, and email notifications.

## Features

- Job search and filtering by location and category
- User login and registration
- Apply for jobs with PDF resume upload
- Email confirmation after applying
- Application status tracking
- Recruiter dashboard to manage applications

## Tech Stack

- **Frontend:** React.js, JavaScript, HTML, CSS
- **Backend:** Java, Spring Boot
- **Database:** MySQL
- **API:** REST API
- **Email:** Spring Boot Mail, Gmail SMTP

## Project Structure

- `frontend/` – React frontend
- `jobportal-backend/` – Spring Boot backend

## How to Run

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd jobportal-backend
mvn spring-boot:run
```

## Prerequisites

- Java JDK 21
- Maven
- Node.js and npm
- MySQL Server

Configure the MySQL database and email credentials locally before running the application. Do not upload passwords or app passwords to GitHub.
